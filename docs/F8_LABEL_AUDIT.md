# F8 標籤減法審計（盤點與提案，待 Brandon 核可）

日期：2026-10-23　依據：`DESIGN.md`「減法規則」、`PRODUCT.md` 原則 6、`docs/REDESIGN_PLAN_v3.md` F8。
盤點方式：四個模組載入示範病例、全部展開，用程式列出所有看得到的灰色說明句（`.hint`）、小標註記、欄位與勾選項的括號說明、判讀板格子下方小字，共 **112 項**（同一句在多個模組出現算多項）。

## 判斷方式

每項問三題（三題都過才可以減）：
1. 遮住它，藥師還會做對嗎？
2. 它是在重講別處已經有的東西嗎？
3. 它是在解釋臨床藥師早就知道的名詞或藥理嗎？

**不可刪**：單位、估計與實測的區別、院內與參考來源、缺資料原因、警示與限制、狀態字、計算出來的即時數值（例如「對應 AUC/MIC ≈ 500」「目前目標：…」「參考 T1 8.8」）。

手段由輕到重：**①** 版面解決　**②** 搬進滑過提示（title）　**③** 收進「ⓘ 詳細說明」　**④** 刪除（只限整句重複）。
所有改動都只動左欄與右欄的靜態說明文字，不動 render 輸出（golden 比對的區塊不受影響）。

## 保留不動（72 項）

- **單位**（約 30 項）：MIC 假設（µg/mL）、Albumin（g/dL）、CRP（mg/dL 或 mg/L，請標單位）、Trough 結果（µg/mL，即 mg/L）、給藥間隔（小時，τ）等。
- **即時數值與目標**：對應 AUC/MIC ≈ 500、目前目標（院內）…｜UpToDate 參考…、Gentamicin 目前目標…、參考 T1 8.8、判讀板格子下方的「目標 8–10」「MIC 假設 1」「0.77 L/kg」「IBW（Devine）」等。
- **警示與限制**：參考 Cmax(T1)「僅供對照，不納入判讀」、近 24h AUC「輔助參考，本藥物主要仍以 peak/trough 為準」、ARC 勾選框的「不改變任何計算」、正在透析「自動套用腎衰竭校正公式，可手動覆寫」、HLA-B*15:02 警示（前半）。
- **院內規則**：PO／錠劑最小可用單位、本院無 free phenytoin 醫令（01 那一句）。
- **必填與缺資料**：「有給藥紀錄時必選」、AED「尚無足夠的目前劑量與濃度資料可估算（需要…）」、Albumin 為蛋白結合校正必需。
- **定義判斷範圍的舉例**：深部／難清除感染（心內膜炎、骨髓炎、CNS、菌血症）、大量體液蓄積（腹水／燒燙傷 ≥20%…）、不明原因骨痛（合併 ALP 上升）、發燒趨勢（過去 24–48 小時）——這些括號決定「算不算」，搬走會判斷錯。
- **分組小標**：Azole 08 的「肝毒性臨床表現（三藥共通，警覺級）：」等、AED 08 的「Phenytoin 毒性徵象…」。
- **選項後果**：「工具會往前補入虛擬劑次，讓濃度不從零開始累積」、AMG「族群 Vd 先驗上修至 0.35 L/kg」。
- **輸入格式**：藥名／劑量／頻次（每行一項）。
