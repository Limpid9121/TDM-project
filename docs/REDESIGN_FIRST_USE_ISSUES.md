## 優先修的做法（2026-10-23）

- **2**：「處方 ▾」改名「病人 ▾」，第一項就是「開始新病人（清空此頁）」，接著另存為新紀錄、從其他模組帶入、示範病例，最後是「刪除所選病人」；「傳送與備份 ▾」改名「備份 ▾」，只留匯出、匯入、清除本機所有病人資料與共用電腦提醒。四個模組一樣。
- **3**：強調色選擇從頂列移到頁面最下方（定位聲明下面）一行「介面強調色」，頂列只留跟病人有關的東西。
- **7**：不再把判讀板變灰。改成判讀標題下方一條整列的琥珀色橫幅「處方已改，下面的數字還是舊的」＋「展開給藥紀錄並更新」按鈕；數字、曲線、候選方案只是變淡（保留原本顏色）。
- **9**：標籤改成「還沒有濃度時，用哪個族群模型估算」；按鈕寫來源：「模型 A（國際通用・預設）」「模型 B（東亞族群・Oda 2024）」（Brandon 補充：模型 B 是臨床組資深藥師建議找的，族群較接近台灣、預估較準；模型 A 是國際通用模型）；下面一行寫清楚切換會改什麼：判讀板、劑量調整建議與 AI Prompt 的數字跟著換；曲線仍是模型 A；有濃度後改用個體擬合，這列就不顯示。
