| 檔案 | 名稱 | 右區怎麼排 | 招牌想法 |
|---|---|---|---|
| `A.html` | 報告式＋目標帶尺 | 結論區（大數字）→ 目標帶尺 → 候選方案 → 曲線與時間軸 → 參數 → 注意事項 → 監測 → AI Prompt | AUC 目標帶尺：0–800 一把尺，綠框＝目標 400–600，現行處方與候選方案的位置一眼看到；候選方案表每列也有迷你尺 |

## 第二輪（2026-10-21）：C2

Brandon 看完第一輪：三張都不滿意，勉強選 C，回饋三點：
1. 目標帶尺沒用：藥師看到「457，目標 400–600」就知道有沒有達標，不需要圖。同理也拿掉候選方案的同尺長條與半衰期尺。
2. 綠色配色 AI 味重 → 改成黑白灰＋深藍主色＋一個大膽撞色。
3. 右邊要固定在畫面上：不捲動就看得到最重要的資訊，左邊輸入時右邊即時更新；細節與劑量規劃再往下捲。

`C2a.html`（芥末黃）、`C2b.html`（朱紅）、`C2c.html`（洋紅）是同一個版面、三種撞色：
- 右邊面板固定在畫面上（自己可以捲動）。不捲動就看得到：判讀列（現行處方、擬合方式）、數字列（AUC₂₄ 與目標、Cmin、Cmax、t½、CL、Vd）、一行注意事項、曲線與時間軸、候選方案表（含自訂列）。往下捲才是監測與下次抽血、完整參數、AI Prompt。
- 狀態只用文字顏色（綠「目標內」、琥珀「留意」、紅「超標」）加小方塊，不再有大片色塊。
- 撞色只出現在三個地方：頂列下緣一條線、候選方案表的「現行」標籤、曲線上的「現在」標籤。
- 唯一保留的圖是濃度曲線加時間軸：它提供數字給不了的資訊（抽血時點相對給藥的位置）。

**主要目標是 24 吋螢幕（1920×1080）**（Brandon 2026-10-21）：寬度 ≥1600 時曲線與候選方案並排，監測與下次抽血也進到不用捲動的範圍。
