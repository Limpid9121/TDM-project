# TDM 工作台（TDM-project）

整合各類藥物治療藥物監測（TDM）並能存檔追蹤的計算工具。純前端、單一 `index.html`，無後端、無需安裝，所有計算都在瀏覽器本機完成。核心是**自由抽血時點**的藥動學分析：抽血時間不必落在傳統的 peak／trough，任意時點的濃度都能納入擬合。

**線上版**：https://limpid9121.github.io/TDM-project/
**本機使用**：直接以瀏覽器開啟 `index.html`，離線可用。
**設計目標螢幕**：1920×1080 桌機（手機版不支援）。

> ⚠ 本工具為臨床決策輔助，不是醫療器材，未經任何法規審查。內含作者所屬醫療機構的院內規則與參數，他院使用前必須換成自己的院內規定。詳見下方「授權」與「定位聲明」。

## 藥物模組

| 模組 | 狀態 | 做法 |
|---|---|---|
| Vancomycin | 可用 | 一室模型貝氏 MAP 擬合，AUC₂₄ 導向劑量建議；含血液透析（HD）情境 |
| Aminoglycoside | 可用 | Peak／trough 與 Cmax/MIC 評估；含 ODD／HDEI 建議起始間隔、TIW、HD 排程 |
| Azole | 可用 | 規則引擎與情境檢查表（非藥動學擬合） |
| 抗癲癇藥物（phenytoin、valproic acid） | **開發中** | 濃度校正判讀＋情境檢查；數值與介面可能變動，請勿作為臨床依據 |

### Vancomycin

- 自由抽血時點擬合 ke／Vd／CL：2 點還原 Sawchuk-Zaske、1 點貝氏校正、3 點以上更穩健；新舊多次濃度可一起擬合
- 以 AUC₂₄ 為目標比較候選給藥間隔（q6h／q8h／q12h／q24h，可自訂），勾選方案可在曲線上疊畫新處方
- 尚未給藥時可用族群 PK 預測起始劑量；族群模型可在**模型 A**（國際通用，Cockcroft-Gault 線性，Matzke 1984）與**模型 B**（Oda 2024，日本 real-world 資料的二室模型，族群特性較接近台灣病人）之間切換（預設 A）
- Loading 劑量依體重建議；輸注時間依院內規則隨劑量自動帶入（每 500 mg 至少 1 小時）
- 給藥紀錄可依處方自動展開；產生範圍自動帶（分析起點＝loading 或第一劑維持劑量時間，展開至＝最後一次抽血後的下一劑；第一次評估則帶到約 5 個半衰期）
- 給藥紀錄標出每次抽血前後的劑次，可用 −／+ 以 5 分鐘為單位微調實際給藥時間
- 血液透析：勾選星期與時段即可批次產生透析時程，並以透析間期視窗處理擬合

### Aminoglycoside

- 依藥物 × 給藥策略 × 適應症帶出院內目標 peak／trough；Cmax/MIC 療效評估（Moore 1987、Kashuba 1999）
- ODD／HDEI 建議起始間隔依 CrCl 分段（≥60→q24h、40–59→q36h、20–39→q48h、<20 不建議 ODD，依 Hartford nomogram 的分界）；有懷孕、體液分布異常、嗜中性球低下、心內膜炎或 CNS 感染等排除因子時不建議 ODD
- 院內安瓿劑量捨入（依品項換算 mL）；支援 TIW 與 HD 排程

### Azole

Voriconazole、posaconazole、isavuconazole。**規則引擎與情境檢查表**，不是藥動學擬合：trough 對院內目標判讀（UpToDate 數值並列參考）、感染控制趨勢推論（MSG／EORTC）、三級毒性分類、CYP 交互作用偵測、依院內品項的劑量捨入、posaconazole 偽性醛固酮增多症組合警示。

### 介面

- **左欄輸入、右欄判讀**：判讀板把最重要的數字放大（AUC₂₄ 或 Cmax／Cmin），旁邊是目標與狀態字（目標內／留意／超標）
- 右欄捲動有兩個定位：「判讀板＋曲線」與「曲線＋劑量調整建議」，靠近時自動對齊
- 處方改了但給藥紀錄還沒重新展開時，右欄標「尚未更新」並提供一鍵展開，避免把舊數字當成新的
- 時間一律 24 小時制，點時間格有「時｜分」下拉
- 說明預設收起，點「ⓘ 詳細說明」展開；欄位名稱有虛線底的，滑過或 Tab 到欄位可看完整意思
- 同一位病人用兩種藥時，切到空白的模組會出現「帶入基本資料」小卡

### 共通功能

- **病人存檔與追蹤**：依病歷號存檔，每次評估存成一筆收案版本，可切換、匯入與合併。資料只存在使用者自己瀏覽器的 localStorage，**不會上傳**，也不在程式碼或這個 repo 裡。共用電腦請用完從「備份 ▾」清除
- **歷程趨勢**：跨收案的參數與 lab 趨勢，可勾選要顯示的指標
- **AI 諮詢 Prompt**：一鍵產生可貼給任一 AI 的整合評估文字

## 關於存檔與網址

存檔綁定於「同一個瀏覽器＋同一個網址」。使用固定的 Pages 網址比開本機檔案更穩定：本機檔案路徑（`file://...`）改變或重新下載新檔案時，瀏覽器可能視為不同儲存空間，導致存檔對不上。

## 開發與測試

```bash
cd tests && npm install && cd ..
bash tools/run_checks.sh --quick   # 跑全部 jsdom 測試（含 golden-master 與獨立 PK 驗算）
```

- `tests/`：jsdom 回歸測試；`tests/golden/` 是計算與畫面輸出的 golden-master 快照，**任何差異都要人工核可**才能更新
- `tools/shoot_review.py`＋`tools/review_frame.html`：headless Edge 截圖與版面量測（對齊、截字、對比、首屏文字數）
- 改版規則與紅線（計算函式不可改、element id 不可改名等）：`docs/REDESIGN_PLAN_v2.md` 第 0.4 節

## 主要文獻

- Matzke et al. 1984：vancomycin 族群藥動學（模型 A）
- Oda et al. 2024, *J Infect Chemother* 30:1244-1251：vancomycin 二室模型（模型 B）
- 2020 ASHP／IDSA／PIDS／SIDP vancomycin 共識指引
- Moore 1987；Kashuba 1999：aminoglycoside Cmax/MIC ≥ 8
- Hartford nomogram：ODD 間隔依 CrCl 分段
- Tverdek 2017：posaconazole 肝毒性
- MSG／EORTC 反應準則：azole 感染趨勢推論

所有臨床數值與族群參數皆須能追溯到上述或已註明的文獻、院內規定。
